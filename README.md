# Руми: Клинок демонов — 16-bit

Пиксельная браузерная RPG в стиле 16-битных игр, сделанная на HTML Canvas без внешних библиотек.

## Запуск в браузере

Открой файл `index.html` в браузере. На компьютере можно играть с клавиатуры, на телефоне — экранными кнопками.

## Управление

- **WASD / стрелки** — перемещение.
- **Пробел или J** — удар клинком.
- На телефоне используй экранный джойстик и кнопку удара.

## Android APK

В репозитории настроен GitHub Actions workflow для сборки Android APK.

1. Открой вкладку **Actions**.
2. Выбери **Build Rumi 16-bit APK**.
3. Открой последнюю успешную сборку.
4. В разделе **Artifacts** скачай `Rumi-Demon-Blade-16bit-APK`.
5. Распакуй архив и установи APK на Android.

Каждый новый коммит в ветку `main` запускает новую сборку автоматически.

## Технологии

- HTML5 Canvas
- JavaScript
- Пиксельная графика с разрешением игрового холста 320×180
- Android WebView wrapper через GitHub Actions
